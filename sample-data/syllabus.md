# CS 3380 - Database Systems - Syllabus

## Course Description

An introduction to database design and management, covering relational
theory, normalization, SQL, transactions, and an overview of NoSQL
systems.

## Grading

- Homework: 30%
- Midterm: 25%
- Final project: 30%
- Participation: 15%

## Attendance Policy

Two or more unexcused absences before the midterm may result in a
one-letter-grade reduction. Excused absences require documentation
submitted within one week.

## Weekly Topics

1. Introduction to databases, the relational model
2. Keys, constraints, and primary keys
3. Normalization (1NF, 2NF, 3NF)
4. SQL: SELECT, JOIN, GROUP BY
5. Transactions and ACID
6. Indexing and query performance
7. NoSQL and document databases
